What can AI agents create with GISMap?

Finished maps, briefings, guided tours, field task packages, 3D maps and themed maps. Each recipe has its own page and JSON document (agent-recipe-v1) with the exact interface, a tested example and its limits.

Recipes are composable. For a 3D California grape map with autumn colors, a five-slide briefing and a QR code, combine interactive-map, spatial-3d-chart, vibe-map and interactive-briefing in one consistent project. Verify compatibility, exports and reopening.

Current limitations: map and briefing functionality uses GISMap's client-side API. Tours and field tasks use existing workflows, not a universal hosted authoring API. REST/MCP authoring, full engine parity, and complete project round-trip verification are not yet available. The implementation specification describes a goal, not a claim that every feature is implemented.

Install

Download and extract the ZIP. Copy the extracted gismap directory into one of these directories:

  • Claude Code: .claude/skills/ in a project, or ~/.claude/skills/ for your user.
  • Codex: .agents/skills/ in a project, or ~/.agents/skills/ for your user.

For a repository checkout, project-local installations can instead symlink to the canonical skills/gismap directory. See the current Claude Code and Codex documentation.

Eight agent recipes

Discover → inspect → plan → validate → execute → verify → share. Details, exact execution environments, inputs, examples and limitations are in the recipe reference.

Interactive map

Inspect a source, construct a filter and renderer, validate a map-v1 specification, create a share link, and check it in the map. For follow-ups, preserve the existing map and create new artifacts: see the California fire refinement example. See an example or guide · Recipe details

Interactive briefing

Build ordered slides with selected features and contextual layers. Verify spatial analysis, slide navigation and reopening. See an example or guide · Recipe details

Geographic tour

Resolve locations and preserve stop order, then configure cameras, descriptions and navigation. Build the link with createEmbeddedTourUrl from tour-share.js; no app session is needed. A flyover is not road routing. See an example or guide · Recipe details

Field tasks

Use the existing assignment and reporting workflow. Build the assignment link with createFieldTaskUrl from field-task-share.js. Preserve requested tasks, and do not treat sample reports as real completion. See an example or guide · Recipe details

3D extrusion

Inspect polygon geometry and height fields, check engine compatibility, then verify rendered heights and share persistence. See an example or guide · Recipe details

3D spatial chart

Separate polygon events into explicit virtual-Z strata or footprint slabs, preserve the source geometry, label the Z-axis meaning, and optionally generate a five-scene Brief. Current analytical limits are explicit. Recipe details

LiDAR and 3D models

Put LAS/LAZ point clouds and glTF, OBJ or PLY models (CAD exports) on a 3D map with three.js: ASPRS class colours and filters for wires, towers and vegetation, true colour, elevation or intensity. Works in a #map=json: link on the MapLibre engine. Recipe page · Recipe details

Vibe-matched map

Coordinate supported interface skin, basemap and layer symbology; verify contrast and what survives sharing. See an example or guide · Recipe details
