Dashboards, charts and animation

An agent can create an Instant Dashboard from an inspected loaded queryable layer. It selects a data-aware count or measure chart, applies an interface skin and readable basemap, and preserves a legible layer renderer. A selected bar, donut segment or other grouped mark must filter/select its matching map records, and the agent must verify that clearing the filter returns the prior map data.

Chart Builder supports bar, column, line, area, histogram, scatter, bubble, box, donut, metric, conventional 3D bar/scatter and map-chart presets. The chart can go to a panel, Instant Dashboard, map or Brief slide; its scope can be filtered, all, viewport or selected data. A chart built from bounded or sampled data must be labeled accordingly.

Cinematic mode presents observed records or explicit numeric scenarios; it does not infer movement or causal change. Confirm source date/time or numeric semantics, avoid hiding the source with visual effects, test local and overview scales, respect reduced motion, and pause/remove an effect before removing the layer. Verify that no ghost overlay remains. Read the complete dashboard and animation reference.

Share and embed

A configured public map can be shared as a link or a paste-ready iframe. An embed preserves public layers, styles, filters, camera, basemap and skin. Test it in its destination site: a generated iframe is only prepared until it is rendered there. Local, device-only, private and credentialed sources cannot be embedded. See Sharing & embedding.

Verify before reporting success. Say whether work is prepared, validated, loaded or verified. A plausible URL, iframe or animation setting alone is not verification.

Install

Download and extract the ZIP. Copy the gismap directory into .claude/skills/ or .agents/skills/ in a project, or the equivalent user-level skill directory.

Version and maintenance

Skill version 0.1.2. The ZIP is built from the canonical directory with python3 scripts/build-skill-zip.py; use --check to verify it is current. Never place credentials or private data in public share links.
