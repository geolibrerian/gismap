GISMap Online Agent Skill

Help Claude Code, Codex and other Agent Skills compatible assistants create interactive geographic maps and briefings, and work with guided tours, field tasks and sharing.

AI documentation (llms.txt) · Download the skill ZIP · Read SKILL.md · Read the implementation specification · API capabilities · Agent guide

Current limitations: map and briefing functionality uses GISMap's client-side API. Tours and field tasks use existing workflows, not a universal hosted authoring API. REST/MCP authoring, full engine parity, and complete project round-trip verification are not yet available. The implementation specification describes a goal, not a claim that every feature is implemented.

Install

Download and extract the ZIP. Copy the extracted gismap directory into one of these directories:

  • Claude Code: .claude/skills/ in a project, or ~/.claude/skills/ for your user.
  • Codex: .agents/skills/ in a project, or ~/.agents/skills/ for your user.

For a repository checkout, project-local installations can instead symlink to the canonical skills/gismap directory. See the current Claude Code and Codex documentation.

Try asking

  • Inspect this public GeoJSON and make a shareable map.
  • Build a county choropleth and explain the data and classification.
  • Create a geographic briefing, or help me build a guided tour or field task.

Version and maintenance
