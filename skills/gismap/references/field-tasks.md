# Field tasks

Use the existing Field Tasks UI and sharing workflow. Assignments and returned reports are distinct: never fabricate participant check-ins, photos or completion. Current compact links have limits (up to five features and ten steps; see `js/field-task-share.js` in the repository). Do not assume photo enforcement, mandatory accounts or server persistence. There is not yet a universal external field-task authoring API. Verify task content after reopening before sharing.
