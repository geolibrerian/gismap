# Field tasks

Use the existing Field Tasks UI and sharing workflow. Assignments and returned reports are distinct: never fabricate participant check-ins, photos or completion. Current compact links have limits (up to five features and ten steps; see `js/field-task-share.js` in the repository). Do not assume photo enforcement, mandatory accounts or server persistence. There is no hosted field-task authoring API. Agents build the assignment link with the standalone module `https://gismap.online/js/field-task-share.js`: `createFieldTaskUrl({ baseUrl: "https://gismap.online/", task: { id, title, location, latitude, longitude, notes, steps: [{ text }], features: [{ layerUrl, objectId, latitude, longitude, label }] } })`, and check it with `decodeFieldTask`. Each requested task becomes a step; more than five tasks become several packages. Photos stay on the field device and go into its PDF report. See https://gismap.online/agent-recipes/field-tasks/. Verify task content after reopening before sharing.
