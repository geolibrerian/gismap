# Tours

Use the existing GISMap guided-tour UI or documented examples at https://gismap.online/examples/. Existing camera-only links contain ordered chapter locations, camera, title, caption, basemap, transition and linger; other content may not be included. The current `map-v1` format is not a generic tour spec and there is no hosted tour-authoring API. Without code, write `https://gismap.online/?tourOnly=1#tour=json:<URI-encoded JSON>` with `{ "title", "autoplay", "stops": [{ "name", "caption", "lat", "lon", "zoom", "tilt", "heading", "basemap", "seconds" }] }`. For a shorter, QR-safe link, build it with the standalone module `https://gismap.online/js/tour-share.js`: `createEmbeddedTourUrl({ baseUrl: "https://gismap.online/", presentation: { title, skin, playbackMode, chapters: [{ title, body, viewState: { center: [lon, lat], zoom, tilt, heading }, basemapId, lingerSeconds, transitionMode }] }, allowedBasemaps: new Set([...ids]), tourOnly: true })`, and check it with `decodeEmbeddedTour`. Captions are cut to 80 characters and links to 2,800. On the MapLibre engine (the default) `satellite` is drawn as a street map; use `usgs-imagery` for aerial imagery in the United States. See https://gismap.online/agent-recipes/geographic-tour/. Verify navigation and camera after reopening; export a `.gisatlas` if the link exceeds the QR-safe limit.
