# Tours

Use the existing GISMap guided-tour UI or documented examples at https://gismap.online/examples/. Existing camera-only links contain ordered chapter locations, camera, title, caption, basemap, transition and linger; other content may not be included. The current `map-v1` format is not a generic tour spec and no standalone hosted tour-authoring API is advertised. Verify navigation and camera after reopening; export a `.gmoatlas` if the link exceeds the QR-safe limit.
