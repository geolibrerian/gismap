Agent guide

Making maps with an AI agent

GIS Map Online opens a map from a link. An agent that can only write text can make a map by writing one JSON object into a URL; agents that run code or drive a browser get validation, statistics and live control. No API key, account or server call is needed.

1. Chat-only model: write a link

Look at the service's fields first by opening the layer URL with ?f=pjson appended, and pick a numeric field. Then write a map-v1 spec and put it after #map=json: in the address (URI-encode it when you can).

Worked example: U.S. county corn sales. The publisher's own style labels -1 as "Not Disclosed" (546 of 3,074 counties), so -1 is listed in exclude: those counties are drawn grey as "No data" instead of pulling the colour classes down. sources.inspect reports codes like this as sentinels.

"method": "auto" lets the app choose the class breaks from the data (corn sales are skewed, so it picks quantile classes). Not sure which style suits a field at all? Write { "type": "auto", "field": "CORN_SALES_IN_DOLLARS" } and the app chooses. Saving or sharing from the app records the chosen classes, so the map then looks the same for everyone.

{
  "version": 1,
  "basemap": "gray-vector",
  "layers": [
    {
      "url": "https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0",
      "renderer": {
        "type": "choropleth",
        "field": "CORN_SALES_IN_DOLLARS",
        "method": "auto",
        "ramp": "greens",
        "exclude": [
          -1
        ]
      }
    }
  ]
}

Link: https://gismap.online/#map=json:%7B%22version%22%3A1%2C%22basemap%22%3A%22gray-vector%2…

For one layer and one field there is a shorter form with no JSON: https://gismap.online/?layer=https%3A%2F%2Fservices.arcgis.com%2FP3ePLMYs2RVChkJx%2FArc…

2. Code-running agent: inspect, validate, link

Import the pure core (a browser, Deno, or Node with a clone of the repository: import ./js/gismap-core.js), inspect the source, validate the spec, and create a link. Python can build the readable link by hand.

import { sources, mapSpec } from "https://gismap.online/js/gismap-core.js";

const url = "https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0";
const meta = await sources.inspect(url); // fields, scale range, freshness, sentinels
const exclude = meta.sentinels
  .filter((code) => code.field === "CORN_SALES_IN_DOLLARS" && code.source !== "heuristic")
  .map((code) => code.value); // [-1]
const spec = { version: 1, basemap: "gray-vector", layers: [{ url, renderer: { type: "choropleth", field: "CORN_SALES_IN_DOLLARS", exclude } }] };
const { valid, issues } = mapSpec.validate(spec);
const { url: link, qr } = await mapSpec.createLink(spec); // compressed; { compress: false } gives #map=json:
import json, urllib.parse

spec = {"version": 1, "basemap": "gray-vector", "layers": [{"url": "https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0",
        "renderer": {"type": "choropleth", "field": "CORN_SALES_IN_DOLLARS", "exclude": [-1]}}]}
link = "https://gismap.online/#map=json:" + urllib.parse.quote(json.dumps(spec, separators=(",", ":")), safe="")

3. Browser-automation agent: drive the page

Wait for gisMapOnline.ready (or the gismap:ready event, or <html data-gismap-state="ready">), add layers, fit the camera, and read describe() to check the result. layers.suggestStyles ranks the styles that suit a field, each with a reason and its class breaks; apply one with its pinnedSpec.

await gisMapOnline.ready;
const layer = await gisMapOnline.layers.add("https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0", {
  renderer: { type: "choropleth", field: "CORN_SALES_IN_DOLLARS", ramp: "greens" }, // sentinels excluded by default
});
await gisMapOnline.camera.fitTo(layer.id);
const { options } = await gisMapOnline.layers.suggestStyles(layer.id, { field: "CORN_SALES_IN_DOLLARS" });
await gisMapOnline.layers.update(layer.id, { renderer: options[0].pinnedSpec }); // the recommended style
console.log(gisMapOnline.describe().state); // layers, basemap, camera, issues
const { url } = await gisMapOnline.mapSpec.createLink(gisMapOnline.mapSpec.fromCurrent());

4. Handling errors

Every error from the API is a GisMapError with a code and a hint written for agents. When a map spec opens, problems are listed in describe().state.issues instead of stopping the map.

CodeWhat to do
INVALID_URLPass a complete https:// URL to a service, layer or file.
HTTPS_REQUIREDUse the https:// form of the URL; GIS Map Online only loads remote data over HTTPS.
CREDENTIAL_IN_URLRemove the token, key or password from the URL. Only public services can be shared.
UNSUPPORTED_LAYER_TYPEUse one of the layer types listed in capabilities.json (arcgis-auto, feature, map-image, imagery, geojson, wms, wfs, kml).
TOO_MANY_LAYERSA map holds at most 10 data layers. Remove one with layers.remove before adding another.
LAYER_LOAD_FAILEDCheck the URL in a browser with ?f=pjson appended. The service may be down, private or not a layer URL.
CORS_BLOCKEDThe publisher does not allow browser access to this service. Use another source, or download the data and add it as a file.
SERVICE_ERRORThe service answered with an error. Check the URL, the layer number and any filter for typos.
FIELD_NOT_FOUNDUse a field name exactly as the service lists it; sources.inspect(url) returns the fields.
INVALID_SPECFix the listed issues; the schema in capabilities.json describes every property.
NOT_READYAwait gisMapOnline.ready before calling this.
NOT_FOUNDCall layers.list() to see the layers on the map and their ids.
SPEC_TOO_LONGShorten the spec (fewer layers, no raw ArcGIS renderers) or use the compressed #map= form from mapSpec.createLink, or host the JSON and link to it with ?spec=.

5. Data caveats

  • Sentinels: some services store codes such as -1 or -9999 for "not disclosed" or "no data". sources.inspect and layers.list() report them; statistics leave them out and choropleths draw them as "No data". Sample-based guesses (source: heuristic) are reported but never applied.
  • Scale ranges: a publisher can hide a layer above or below a scale (Corn hides itself zoomed in past 1:144,447). Set ignoreServiceScaleRange: true to draw it at every zoom.
  • Record limits: services return at most maxRecordCount features per request. Statistics computed from loaded features are labelled as a sample when the layer has more.
  • Freshness: sources.inspect and layers.list() give dataLastEditDate; say how current the data is when you describe it.
  • Access: services must be public, HTTPS and allow browser (CORS) access. URLs with tokens or keys are refused.
Privacy by design. GISMap runs in the browser. Remote services are requested from their publishers, and local files stay on the device unless you choose to export or share them elsewhere.
