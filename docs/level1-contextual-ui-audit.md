# Level 1 contextual UI: architecture audit and initial slice

GISMap is a static HTML/CSS and ES-module application; `js/app.js` initializes the event bus, engine-neutral map controller, project manager, application runtime and UI controller. MapLibre and ArcGIS implement the map adapter. The layer records exposed by `getLayers()` carry geometry, fields and query capabilities. `ApplicationState` tracks active layer, selection and filters; identify results are bridged into it by `ApplicationRuntime`.

The existing `PanelManager`, `MobilePanelManager` and `LayoutManager` own panel placement, compact layouts and application presets. Display settings store panel visibility and sizes; project files, shared URLs and application configurations have their own persistence. Map Insight already owns feature inspection, while Cartography Lab owns styling, filtering and 3D configuration, and the attribute table owns record inspection. Notes, field workflows, Briefs and Tours have existing controllers; DuckDB is an optional browser-side analysis client. Skins and responsive rules use CSS variables and existing breakpoints. Tests use Node's built-in test runner (`node --test tests/*.test.mjs`).

The contextual slice in `js/contextual-workspace.js` derives recommendations from metadata. For local queryable layers only, it also samples at most 100 records, reports sample coverage and computes bounded field statistics; it does not query remote services to profile them. The UI renders dismissible suggestions in the desktop Layers panel and a compact map surface on mobile, and delegates actions to existing tools, including the Cartography Lab's Filter tab. Selection defers to Map Insight, which presents a readable feature label and a short attribute summary with all other returned attributes available on demand. Suggestions never move or close panels. Dismissal is remembered in browser storage per project and source, with a Show suggestions control to restore it. `?contextDebug` adds an expandable diagnostic view and exposes the latest rule, profile, actions and suppression state as `window.gisMapContextDebug`.

This is a foundation, not the complete Level 1 specification: metadata coverage varies by adapter; remote progressive profiling, panel pinning, fuller workflow-aware suppression, richer feature actions, panel simplification and workspace restore/reset remain future work. Sample statistics are not full-dataset statistics. No model or backend is required for this slice.
