Both engines open the same public data and preserve the same project context. Choose the one whose visual and analysis capabilities fit the work in front of you.

Practical guide

Which one should I use?

Open data and cinematic maps

Start with MapLibre for fast open basemaps, local browser workflows, 3D terrain, and decorative cinematic layers. Its renderer is intentionally a compatibility layer for common ArcGIS styles.

Exact ArcGIS service behavior

Use ArcGIS when a service needs its native renderer, a picture-marker SVG, KML, or an ArcGIS-specific capability. It loads the ArcGIS SDK only for that session.

Keep the choice reversible

Engine selection changes how GISMap draws a map; it does not change the underlying features. If a style is unsupported, GISMap explains the limitation and points to the compatible engine.
