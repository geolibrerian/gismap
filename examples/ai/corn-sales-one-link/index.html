Chatbot · no code · readable link

A styled map in one link, written by a chatbot

The whole map is one JSON object after #map=json: in the address. A model that can only write text can produce it; GIS Map Online validates it, opens whatever is valid and lists anything it skipped. Two details make the map honest: -1 means "Not Disclosed" in this data, so it is excluded, and "method": "auto" lets the app choose class breaks that suit the skewed values.

What it shows off

  • A readable #map=json: link that a chat-only model can write by hand
  • "exclude": [-1]: the publisher's "Not Disclosed" code is drawn as No data instead of distorting the classes
  • "method": "auto": the app picks quantile classes because corn sales are heavily skewed

Ask a chatbot

This works in any chatbot, with or without tools:

Make a GIS Map Online link for U.S. corn sales by county. The layer is https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0; look at its fields with ?f=pjson and use CORN_SALES_IN_DOLLARS. Write a map-v1 spec (https://gismap.online/schemas/map-v1.schema.json) with a choropleth renderer, ramp "greens", method "auto" and a gray basemap. The publisher codes undisclosed counties as -1, so exclude -1. URI-encode the JSON and put it after https://gismap.online/#map=json: and give me the link.

For a code-running agent

An agent can find the -1 code itself instead of being told: sources.inspect reads the publisher's own style and reports it as a sentinel.

import { sources, mapSpec } from "https://gismap.online/js/gismap-core.js";

const url = "https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Corn/FeatureServer/0";
const meta = await sources.inspect(url);
const exclude = meta.sentinels.filter((code) => code.field === "CORN_SALES_IN_DOLLARS" && code.source !== "heuristic").map((code) => code.value); // [-1]
const spec = { version: 1, basemap: "gray-vector", layers: [{ url, renderer: { type: "choropleth", field: "CORN_SALES_IN_DOLLARS", method: "auto", ramp: "greens", exclude } }] };
const { valid } = mapSpec.validate(spec);
const { url: link } = await mapSpec.createLink(spec, { compress: false }); // the readable #map=json: form
