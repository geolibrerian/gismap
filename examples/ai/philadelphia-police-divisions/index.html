Chatbot · briefing link and QR code

A seven-slide briefing from one chatbot prompt

This briefing came from a single prompt to a chatbot that can run code. It found the right layer, wrote seven slides with map views and captions, and returned a link and a QR code that open the whole presentation. No account, server or desktop GIS was involved.

Present the finished briefingAll AI examples

What it shows off

  • A briefing document (slides, map views, captions, a key number) written by a model and opened from a link
  • A slides-only link: ?layer= loads the data, #briefing= carries the slides
  • A QR code that opens the exact same presentation on a phone
  • Honest framing: division boundaries, not crime statistics

Ask a chatbot

Paste this into a chatbot that can run code (so it can compress the briefing into a link). It names the layer, the slides, what not to load and what not to claim.

Use GISMap.online to make a seven-slide interactive briefing from the Philadelphia Police Divisions polygon layer at https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Philadelphia_Crime_Map_WFL1/FeatureServer/1. Include a title slide; a citywide view; North/Northeast, Center City and West/Southwest views; a slide explaining the DIV_NAME field; and a slide about the source and its limitations. Load only the Police_Divisions layer, not the crime incident points (layer 0). Follow the briefing schema at https://gismap.online/schemas/briefing-v1.schema.json and the guide at https://gismap.online/guides/ai-agents/. Output a GISMap briefing link, the editable briefing JSON, and a QR code that opens the same link. Do not invent crime totals or imply the boundaries are current.

For a code-running agent

An agent with Node, Deno or a browser can skip the chat and build the same link with the GISMap core: validate the briefing document, then make the slides-only link with the layer in its query string.

import { briefing } from "https://gismap.online/js/gismap-core.js";

const LAYER = "https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Philadelphia_Crime_Map_WFL1/FeatureServer/1";
const doc = await (await fetch("https://gismap.online/examples/ai/philadelphia-police-divisions/briefing.json")).json();

const { valid, issues } = briefing.validate(doc);    // check before sharing
const url = await briefing.createLink({
  baseUrl: `https://gismap.online/?layer=${encodeURIComponent(LAYER)}`, // the layer travels in the query string
  briefing: doc,
  qrSafe: true,                                      // fails if the link is too long for a QR code
});

Open the Philadelphia police divisions briefing in GIS Map Online. Everything it needs is in the link (1,693 characters): no account, no server, no upload.

Check before you share

  • The layer shows police division boundaries, not reported crime. No slide shows crime rates or incident counts.
  • The source layer was last edited on September 22, 2021; check for newer boundaries before operational use.
  • The slides-only link is long (about 1,700 characters); print the QR code large and test it on a phone first.
