A police divisions briefing, from one prompt or one click

Nine slides on a dark 3D map: a title slide, a count, one slide framed on each of Philadelphia's six police divisions with the police districts drawn over them, and a sources slide. This version was drafted in GIS Map Online itself, with Make a briefing from this view; the prompt and the agent recipe below make the same kind of briefing from scratch. Either way, the whole presentation travels in one link: layers, styles, basemap, look and slides.

Present the briefingAll AI examples

What it shows off

  • Two layers in one briefing: the divisions it is about, and the districts as context
  • A slide per division, each framed on its feature, with its attributes
  • A key number computed from the data (six divisions)
  • A full briefing link that carries the layers, styles, 3D basemap, look and camera with the slides
  • A QR code that opens the same presentation on a phone

Ask a chatbot

Paste this into a chatbot that can run code (so it can compress the result into a link). It names both layers, the slides, what not to load and what not to claim.

Use GISMap.online to make an interactive briefing of Philadelphia's police divisions. Main layer: https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Philadelphia_Crime_Map_WFL1/FeatureServer/1 (Police_Divisions). Second layer, as context: https://services.arcgis.com/P3ePLMYs2RVChkJx/ArcGIS/rest/services/Philadelphia_Crime_Map_WFL1/FeatureServer/2 (Police_Districts) at 75% opacity. Do not load the crime incident points (layer 0). Slides: a title slide, an "At a glance" slide counting the divisions, one feature slide per division framed on it (DIV_NAME is the division name), and a sources slide linking the layers. Use a dark 3D basemap. Write it as one map-v1 spec with the briefing inside (https://gismap.online/schemas/map-v1.schema.json, https://gismap.online/schemas/briefing-v1.schema.json; see https://gismap.online/guides/ai-agents/) and return the link and a QR code. Do not invent crime totals or imply the boundaries are current.

For a code-running agent

An agent with Node, Deno or a browser writes the map and its slides as one map-v1 spec, validates it, and makes the link with the GISMap core. A link whose spec carries slides opens presenting them.

import { mapSpec } from "https://gismap.online/js/gismap-core.js";

// Two layers, a dark 3D basemap and the nine slides (see map.json for the full spec).
const spec = await (await fetch("https://gismap.online/examples/ai/philadelphia-police-divisions/map.json")).json();
// spec.layers: [{ url: ".../FeatureServer/1", title: "Police Divisions" },
//               { url: ".../FeatureServer/2", title: "Police Districts", opacity: 0.75 }]
// spec.briefing.slides: title, "At a glance", one { template: "feature", featureId, fit: "feature" } per division, sources

const { valid, issues } = mapSpec.validate(spec); // check before sharing
const { url, qr } = await mapSpec.createLink(spec); // qr: true when the link fits a QR code

Check before you share

  • The layers show police division and district boundaries, not reported crime. No slide shows crime rates or incident counts.
  • The division slides list the layer's fields as published: DIV_NAME, and geometry measurements such as PERIMETER and Shape__Area.
  • The source layers were last edited on September 22, 2021; check for newer boundaries before operational use.
