How to refine

Inspect the source metadata and filter first. Start with a map-v1 specification or reconstruct a simple parameter URL; clone it, replace only the renderer, validate each clone and generate independent links. In an authorized browser use mapSpec.fromCurrent() to capture current context. The agent guide contains the executable recipe.

Check before sharing

The live public service returned 3,112 records for the filter when checked on 2026-10-20; its data can change. Category rendering depends on the data actually sampled; confirm all 11 years and legend entries in the running map. Acreage uses five quantile classes computed from available data, not fixed breakpoints. Layer opacity affects fills and outlines; the portable category renderer has no independent outline setting. No numeric year slider is specified in map-v1. Test loading, styles, legend and reopening before calling either map verified.
