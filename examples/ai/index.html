AI examples

Maps and briefings made by chatbots and agents.

GIS Map Online opens a map, its styles and its slides from a link. A chatbot can write that link; an agent can check the data first and build richer briefings. Each example below has the prompt, the agent's code, and the finished result to open or scan.

Philadelphia's six police divisions, with the police districts inside them, as a nine-slide interactive briefing on a dark 3D map, opened from one link or QR code.

A two-layer briefing with spatial queries, built by an agent

An AI agent built a ten-slide briefing that shows each state with only the Major League ballparks inside it, using a spatial query per slide, an automatic style and cut transitions.

Chatbot

A styled map in one link, written by a chatbot

Any chatbot, even one that cannot run code, can make a styled county map by writing one JSON object into a link: corn sales by county, with "Not Disclosed" counties kept out of the colour classes.
