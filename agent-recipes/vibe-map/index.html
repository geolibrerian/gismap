Vibe-matched map and presentation skin

Can an AI agent make a map whose look matches the subject, like a Halloween map of California colleges?

Yes, within the preset skins. The agent picks an interface skin, draws the basemap in the skin's colors (basemap "skin" on MapLibre) and colors the data with its own renderer. In an active map session it can also create an Instant Dashboard with linked chart filtering, then share a public-map embed when the map is ready.

Machine-readable recipeAll recipes

Ask for it like this

  • “Make the map feel like Halloween in California”
  • “Theme this map in team colors”
  • “Give this forest map an autumn look”
  • “Create an instant dashboard with a skin and basemap that suit this data”

Inputs

Accepts: Any styled layer. Engines: maplibre, arcgis.

  • source: The data layer.
  • theme: Subject, place, season or mood.

Optional:

  • colors: Preferred colors; say whether they are official, user-provided or merely inspired.
  • parts: Apply skin, basemap theme and data colors together or separately.

Steps

Discover → inspect → plan → validate → execute → verify → share. Each step names where it runs; none is a hosted REST endpoint.

  1. discover: Read llms.txt, this recipe and api/capabilities.json; note the engine and execution environment you actually have. (Declarative URL; https://gismap.online/llms.txt, https://gismap.online/api/capabilities.json, https://gismap.online/api/manifest.json)
  2. inspect: Read the source metadata: geometry type, field names and types, spatial reference, extent, sentinels and query support. Query real values before filtering; never invent fields. (Declarative URL, Standalone JavaScript, In-browser API; <layer URL>?f=pjson, sources.inspect, sources.detectSentinels, layers.metadata)
  3. plan: Write a semantic palette (background, land, water, roads, labels, highlights, data colors, panel accent), then map it onto: a preset skin (map-v1 skin), the skin basemap, and the data renderer's colors. Check text and data contrast. (Declarative URL; https://gismap.online/schemas/map-v1.schema.json, map-v1 skin, map-v1 basemap: skin)
  4. validate: Validate the spec; an unknown skin or basemap is reported. (Standalone JavaScript, In-browser API; mapSpec.validate)
  5. execute: Write the #map=json: link with skin, basemap "skin" and the renderer colors. In an active assistant session, use create_instant_dashboard after inspecting a loaded queryable layer when the requested outcome includes a dashboard; it creates a linked chart panel, skin and basemap. (Declarative URL, Standalone JavaScript, In-browser API; mapSpec.createLink, create_instant_dashboard)
  6. verify: Open the link: skin applied to panels, basemap drawn in skin colors (MapLibre), symbols in the requested colors, labels readable. For an Instant Dashboard, activate a grouped chart mark, verify the matching map filter/selection, then clear it. (In-browser API; describe, mapSpec.fromCurrent, create_instant_dashboard)
  7. share: Return the link; say which palette parts were approximated by a preset. If the user wants a web embed, use get_map_embed or createEmbedIframe only for public layers, then test the iframe in its destination page. (Declarative URL, In-browser API; mapSpec.createLink, get_map_embed, embed-share.js)

Result

map-v1 with skin, basemap (often "skin") and renderer colors. Schema: /schemas/map-v1.schema.json.

  • Themed interactive map link · Declarative URL
  • Project file with custom colors · Outside GISMap. Custom skin and basemap palettes made in the app's skin editor are saved in projects but not in links.
  • Public map embed iframe · In-browser API. Preserves public map configuration; local, private and credentialed sources cannot be embedded.

Verify before reporting success

  • Skin applied
  • Basemap themed where supported (MapLibre skin basemap)
  • Data colors and legend match
  • Labels and data readable
  • Theme persists on reopening
  • Instant Dashboard chart selection filters and clears matching map data when requested
  • Embed tested in the destination page when requested
  • Unsupported parts reported

Report prepared, validated, loaded, rendered and verified separately, and partial or failed when they apply. A generated link alone is only prepared.

Limitations

  • Links carry only the 12 preset skins; exact custom panel and basemap colors are not portable yet.
  • The ArcGIS engine draws the skin basemap as light or dark gray.
  • Raster basemaps (satellite, hybrid) cannot be recolored.
  • Map labels are not configurable in map-v1.
  • Category legends show coded values; RendererSpec categories have no labels.

If something goes wrong

  • If a requested color cannot be matched, choose the closest preset skin and state the difference.
  • On ArcGIS, switch to MapLibre for a themed basemap or accept the gray canvas.

Examples

Example · rendered · checked 2026-10-21

Halloween California colleges

Prompt: “Create a Halloween-themed map of California colleges: midnight purple background, pumpkin orange accents, amber college symbols, green highlights, and a matching skin.”

Data: Colleges and Universities (HIFLD / IPEDS)

Open the result

map-v1 JSON
{
  "version": 1,
  "title": "California four-year colleges, Halloween edition",
  "basemap": "skin",
  "skin": "velvet-orbit",
  "camera": {
    "center": [
      -120.2,
      37.4
    ],
    "zoom": 5.4
  },
  "legend": true,
  "layers": [
    {
      "url": "https://services2.arcgis.com/FiaPA4ga0iQKduv3/arcgis/rest/services/Colleges_and_Universities_View/FeatureServer/0",
      "type": "feature",
      "title": "Four-year colleges and universities",
      "where": "STABBR = 'CA' AND ICLEVEL = 1",
      "renderer": {
        "type": "categories",
        "field": "CONTROL",
        "colors": {
          "1": "#ffb000",
          "2": "#ff7518",
          "3": "#7cfc00"
        }
      }
    }
  ]
}

What was checked:

  • Opened headless on MapLibre: 288 four-year colleges loaded; Velvet Orbit skin and the midnight-purple skin basemap (applied a few seconds after load); amber, pumpkin and green symbols by CONTROL; screenshot inspected.
  • The legend lists the coded values (1 Public, 2 Private not-for-profit, 3 Private for-profit) rather than their names.
  • Midnight purple and pumpkin orange come from the preset skin; exact custom colors and green label highlights are not expressible in links.
