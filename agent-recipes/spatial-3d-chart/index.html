3D spatial chart (strata, footprint stacks)

Can an AI agent separate overlapping events by year in 3D?

On the MapLibre engine, yes: a spatialChart lifts each group (such as a year) into its own virtual-Z slot, or extrudes by a measure, without changing the source polygons. It is a display technique, not overlay analysis.

Machine-readable recipeAll recipes

Ask for it like this

  • “Separate overlapping fire perimeters by year”
  • “Stack these events in 3D by year”
  • “Make a five-part 3D brief of fire history”

Inputs

Accepts: Polygon layer with a group (year) field. Engines: maplibre, arcgis.

  • source: Polygon layer.
  • groupBy: Field with at most 40 distinct values.

Optional:

  • heightField: Nonnegative numeric field.
  • slotMeters: Slot height.
  • gapMeters: Gap between slots.

Steps

Discover → inspect → plan → validate → execute → verify → share. Each step names where it runs; none is a hosted REST endpoint.

  1. discover: Read llms.txt, this recipe and api/capabilities.json; note the engine and execution environment you actually have. (Declarative URL; https://gismap.online/llms.txt, https://gismap.online/api/capabilities.json, https://gismap.online/api/manifest.json)
  2. inspect: Read the source metadata: geometry type, field names and types, spatial reference, extent, sentinels and query support. Query real values before filtering; never invent fields. (Declarative URL, Standalone JavaScript, In-browser API; <layer URL>?f=pjson, sources.inspect, sources.detectSentinels, layers.metadata)
  3. execute: Add spatialChart to the map-v1 layer, or call briefing.generateTemplate({ template: "spatial-3d-chart" }) in the page. (Declarative URL, In-browser API; https://gismap.online/schemas/map-v1.schema.json, briefing.generateTemplate)
  4. verify: Check the Z legend, the strata order and source-event identify. (In-browser API; layers.list)

Result

map-v1 layer.spatialChart, or briefing slides with spatialChart. Schema: /schemas/map-v1.schema.json.

  • Interactive map or briefing link · Declarative URL

Verify before reporting success

  • Z legend states the meaning
  • Groups ordered
  • Restored after the briefing closes

Report prepared, validated, loaded, rendered and verified separately, and partial or failed when they apply. A generated link alone is only prepared.

Limitations

  • MapLibre and ArcGIS engines; the ArcGIS SceneView draws extrude symbols with a meters size variable and Decode() base heights.
  • Fast display: no exact overlap partition or unique-area totals.
  • At most 40 groups.

If something goes wrong

  • Filter the layer or use a coarser group field when there are more than 40 values.
