What can AI agents create with GISMap?

Finished, shareable geographic artifacts: styled maps, slide briefings, guided tours, field task packages, 3D maps and themed maps. Each recipe says which existing interface to use, how to verify the result, and what it cannot do. No account or hosted API is required.
