Guided geographic tour

Can an AI agent create a guided map tour of places in a set order?

Yes, without code. The tour is one link: a chatbot writes https://gismap.online/?tourOnly=1#tour=json:<URI-encoded JSON> with an ordered list of stops (name, caption, lat, lon, zoom, tilt, heading, basemap, seconds). Code-running agents can use the standalone tour-share module for a shorter, QR-safe link.

Machine-readable recipeAll recipes

Ask for it like this

  • “Create a tour of San Francisco landmarks”
  • “Show me these locations in sequence”
  • “Fly between these places with a caption at each”

Inputs

Accepts: Place names or addresses, Coordinates, Features of a public layer. Engines: maplibre, arcgis.

  • title: Tour title (up to 120 characters).
  • stops: Ordered places with verified coordinates.

Optional:

  • captions: Up to 80 characters per stop.
  • camera: Zoom, tilt and heading per stop.
  • basemap: A basemap id: usgs-imagery for aerial imagery on MapLibre (United States), satellite on ArcGIS.
  • linger: Seconds per stop (1–120).
  • autoplay: Start playing on open.

Steps

Discover → inspect → plan → validate → execute → verify → share. Each step names where it runs; none is a hosted REST endpoint.

  1. discover: Read llms.txt, this recipe and api/capabilities.json; note the engine and execution environment you actually have. (Declarative URL; https://gismap.online/llms.txt, https://gismap.online/api/capabilities.json, https://gismap.online/api/manifest.json)
  2. inspect: Resolve every place to coordinates with a real geocoder or layer; ask when a name is ambiguous. Keep the user's order unless asked to reorder. (Outside GISMap, In-browser API; https://nominatim.openstreetmap.org/, layers.list)
  3. plan: Write the chapters: title, caption, viewState {center:[lon,lat], zoom, tilt, heading}, basemapId, lingerSeconds, transitionMode. (Standalone JavaScript; tour-share.js#serializeEmbeddedTour)
  4. execute: Without code: write https://gismap.online/?tourOnly=1#tour=json:<encodeURIComponent(JSON)> with { title, autoplay, stops: [{ name, caption, lat, lon, zoom, tilt, heading, basemap, seconds }] }. With code (browser or Deno): import { createEmbeddedTourUrl } from "https://gismap.online/js/tour-share.js" for a compact, QR-safe link. (Declarative URL, Standalone JavaScript; #tour=json:<payload>, tour-share.js#createEmbeddedTourUrl, tour-share.js#readableTourPayload, tour-share.js#decodeEmbeddedTour)
  5. verify: Decode the link (decodeEmbeddedTour) and compare every stop; with a browser, open it and step through each chapter's camera and basemap. (Standalone JavaScript, In-browser API; tour-share.js#decodeEmbeddedTour, describe)
  6. share: Return the link; add &autoplay=1 to start playing. Longer tours export as .gisatlas from the app. (Declarative URL; #tour=<payload>, ?tourOnly=1, &autoplay=1)

Result

A camera-only tour: { title, skin, playbackMode, chapters[{ title, body, viewState, basemapId, lingerSeconds, transitionMode }] } carried in #tour=.

  • Tour link (#tour=, optionally tour-only) · Standalone JavaScript
  • QR code · Outside GISMap · static. Links are kept under 2,800 characters so any QR encoder can carry them; the app's Share tour dialog also draws one.
  • .gisatlas file · Outside GISMap. Exported in the app (Export guided tour) when a tour is too long for a link.

Verify before reporting success

  • Every stop present in the requested order
  • Coordinates match the geocoded places
  • Camera (zoom, tilt, heading) and basemap per stop
  • Back/Next and Play work
  • Decoded link equals the authored tour

Report prepared, validated, loaded, rendered and verified separately, and partial or failed when they apply. A generated link alone is only prepared.

Limitations

  • A tour moves the camera only; it carries no data layers (use a briefing for data).
  • A flyover is not road routing and gives no travel times.
  • Captions are cut to 80 characters and links to 2,800 characters.
  • On the MapLibre engine (the default), satellite and hybrid are drawn as an OpenFreeMap street map; usgs-imagery is real aerial imagery for the United States.

If something goes wrong

  • If the link exceeds 2,800 characters, shorten captions or split the tour, or export .gisatlas.
  • An unknown basemap id is dropped and the stop falls back to the current basemap; use ids from map-v1.
